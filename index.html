保存研究资料，

Sky Research Backup 使用 rclone，在资料所有者授权后，将备份文件上传至其 Google Drive，并支持下载恢复与文件完整性校验。

工具如何工作

资料所有者通过 Google 授权连接自己的硬盘。文件传输由 rclone 与 Google Drive API 完成；工具运行在资料所有者控制的工作区。

备份保存在所有者的 Google Drive 中，恢复的文件保存在所有者指定的工作区。所有者决定何时备份、恢复或删除资料。

申请的 Google 权限

https://www.googleapis.com/auth/drive.file

此客户端处理通过它创建的文件与文件夹，并读取操作这些文件所需的元数据，以及检查存储空间所需的容量信息。

About this application

Sky Research Backup is a personal backup and restore utility using rclone. After the owner grants Google access, it uploads backup files to the owner's Google Drive, retrieves them into the owner's workspace, and verifies file integrity.

It uses the drive.file scope for files and folders created through this client. The owner controls backup retention, restoration and deletion. Please read the Privacy Policy for details about Google user data.
